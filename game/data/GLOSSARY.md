# 專名點查（無档案员）

查阅方式：**正文里蓝色加下划线专名**，悬停或点击弹出 `tips` 短释（可含维基条目标题提示）。

语法（WebGAL 文本拓展）：

```
[蘆溝橋](style=color:#0B3D91\;font-weight:700\;text-decoration:underline tips=短释。维基：七七事变)
```

注意：tips / style 内的 `;` 必须写成 `\;`。

- 词条权威短释仍维护在 `glossary.json`（供 `glossary.html` 与以后批量注入）
- 剧情中**不再**使用档案员立绘、`callScene:glossary/...` 卷宗对白
- 系统 UI 语言与剧情简繁仍由开场选择 / 引擎设置分别控制
